# Atlas Product Principles

1. Minimise taps.
2. Optimise for standing, walking and one-handed use.
3. Never require navigation if an action can happen in place.
4. Prefer remembering user context over asking again.
5. Relationship management beats data management.
6. Every screen should have one obvious primary action.
7. Conference Mode is the fastest workflow in the app.


Universal Creation Rule

Whenever the user is asked to select an existing entity,
they must always be able to create a new one from the same
context without losing their workflow.

The app should never force:

back
new page
save
return
search again

unless unavoidable.
